Realtime Debug
实时调试技术方案与功能说明

面向测试 / 研发的局域网 & USB 实时调试 SDK。手机端推送网络请求、日志、性能、画面； PC 控制台支持抓包分析、断言、Mock、弱网模拟。已封装为独立模块，第三方两行代码接入。

1. 整体架构

手机 App 内嵌调试桥（WebSocket Server），PC 浏览器通过发现服务定位设备后建立长连接，双向传输：手机上报事件，PC 下发 Mock / 弱网规则。

2. 功能说明

① 抓包与查看

实时网络列表；按方法/状态码/耗时/Mock 过滤；详情 Headers/Body；Replay；复制 cURL；导出 JSON / HAR。

② 断言

控制台本地规则：期望状态码、JSONPath 字段值、最大耗时。命中失败标红并记入结果列表。

③ Mock / 改包

按 URL 包含 + Method 匹配；返回自定义状态码与 Body；Abort 失败；次数限制；单条延迟。规则同步到手机生效。

⑤ 弱网与性能

全局延迟（3G/慢网/自定义）、随机失败率；与 CPU/内存/线程指标、约 1fps 画面预览联动观察。

3. 两种连接方式

局域网模式

同一 Wi‑Fi。手机 UDP 广播 UID；PC 发现或扫端口。控制台输入 UID（登录用户 ID 或 d-xxxx）连接。多机靠 UID 区分。

USB 模式

不同网但 USB 调试已开。控制台执行 adb forward tcp:17890 tcp:17890，浏览器连 ws://127.0.0.1:17890。

4. 研发接入指南（第三方调用）

模块路径：android-playlet-broad/library-realtime-debug/ · 入口类：com.maiya.realtimedebug.RealtimeDebug

  1. 引入模块 
    // settings.gradle
include ':library-realtime-debug'

// 仅 debug / dev，禁止进正式包
devApi project(':library-realtime-debug')
// 或 debugImplementation project(':library-realtime-debug')
  2. Application 启动 + OkHttp 挂载 
    // Application.onCreate（仅测试包）
RealtimeDebug.install(this);
RealtimeDebug.setUidProvider(() -> UserHelper.getInstance().getUserId());

// OkHttpClient.Builder —— 推荐这一行同时挂抓包与 Mock/弱网
RealtimeDebug.installOkHttp(builder);
  3. 启动 PC 控制台 
    library-realtime-debug\console\start-console.bat
# 浏览器打开 http://127.0.0.1:8765/

对外 API 一览

API用途
install(Context)启动 WS / 日志 / 指标 / 画面 / 广播
setUidProvider(...)注入登录 UID，多机发现
installOkHttp(builder)挂载抓包 + Mock/弱网拦截器（推荐）
getUid() / getWsUrl()调试标识与地址
stop()停止服务

5. 控制台使用说明

  1. 手机安装 dev 包并打开 App（过开屏，确保桥已启动）。
  2. PC 运行 console/start-console.bat，打开 http://127.0.0.1:8765/
  3. 连接：
    • 局域网：DoKit → 实时调试 → 复制 UID → 粘贴连接
    • USB：切到 USB →「建立 USB 通道并连接」
  4. 右侧 Tab：请求 / 断言 / Mock / 弱网 / 画面。Mock、弱网改完后点「同步到手机」。
  5. 断言保存在浏览器本地，连接后自动对命中请求校验。

7. 注意事项 & FAQ

  • 必须使用 Dev/Debug 包，正式包不包含本模块。
  • Gradle 依赖请用 devApi / debugImplementation，勿打进 release。
  • 局域网列表为空时：优先用 USB 模式；或确认同网段、防火墙放行 UDP 17891。
  • Mock/弱网改完后必须点「同步到手机」才生效。
  • 系统测试脚本：console/sys_test.py（近期结果 12/12 PASS）。

给研发的一句话
